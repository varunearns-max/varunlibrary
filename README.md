# Varun Library

Quiet textbook-style self-study collection: subject notes, aptitude and math, reference books, previous papers, mock tests and revision notes.

- Chapter 1 — Core Subject Notes (82)
- Chapter 2 — General Aptitude & Engineering Mathematics (84)
- Chapter 3 — Reference Books & Handwritten Materials (215)
- Chapter 4 — Previous Year Papers, 1996 onward (39)
- Chapter 5 — Full-Length Mock Tests (5)
- Chapter 6 — Quick Revision Short Notes (11)

Total: 436 resources · ~478 MB

## Use

Clone (or download ZIP), then open `index.html` in a browser. Everything works offline — search, chapter filters, and the built-in reader.

```powershell
git clone https://github.com/varunearns-max/varunlibrary.git
```

Then open `varunlibrary/index.html`.

Live site: https://varunlibrary.vercel.app

## Study order

1. **Learn** — Core Notes & Reference Books, one subject at a time
2. **Practise** — Chapter tests, previous papers & mocks with a timer
3. **Revise** — Short Notes in the final week
